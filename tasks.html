The internship journey

Eight tasks, one continuous build

Interns progressively work through practical projects — beginning with the TechBridge homepage and eventually combining multiple components into a complete TechBridge internship platform.

30-Day

Structure

The internship runs across a defined 30-day timeline, with each task released in sequence.

8

Practical Tasks

Eight hands-on projects, each building directly on the work completed before it.

→

Progressive Learning

Each task introduces new skills on top of what was already built, rather than starting over.

Project-Based Experience

Every task produces a real, working piece of the TechBridge platform.

The internship roadmap

All eight tasks, in order

From the first line of HTML to a fully connected platform. Difficulty labels below are a suggested progression, not an official TechBridge rating.

  1. 01
    Day 1 Beginner

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    HTML · CSS
  2. 02
    Day 4 Beginner → Intermediate

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    HTML · CSS
  3. 03
    Day 8 Beginner → Intermediate
    You are here

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    HTML · CSS
  4. 04
    Day 11 Intermediate

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    HTML · CSS · JavaScript
  5. 05
    Day 15 Intermediate

    Build the Intern Registration Experience

    Create a professional registration/onboarding interface for TechBridge interns.

    HTML · CSS · JavaScript
  6. 06
    Day 19 Intermediate

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    HTML · CSS · JavaScript
  7. 07
    Day 22 Intermediate → Advanced Beginner

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    HTML · CSS · JavaScript
  8. 08
    Day 26 Intermediate → Advanced Beginner

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    HTML · CSS · JavaScript

How the internship evolves

From first page to full platform

Each stage of the internship builds directly on the last, carrying work forward instead of starting over.

Learn

Understand TechBridge's structure and build the first HTML & CSS page.

Build

Expand the site with a full Programs experience and the internship roadmap.

Enhance

Add JavaScript interactivity with a live task tracker.

Connect

Introduce registration and submission experiences that link interns to the platform.

Complete

Bring every component together into the complete TechBridge platform.
